# Linux Scripts

Учебные bash-скрипты: автоматизация, разбор логов, мониторинг.
Среда: Ubuntu на WSL2.

## Скрипты

- `hello.sh`: переменные и подстановка команд
- `greet.sh`: ввод от пользователя и условия if/else
- `count.sh`: аргументы, проверка папки, цикл по файлам
- `monitor.sh`: запись числа процессов и свободного места на диске в лог (запускался по расписанию через cron)

## Анализ логов

`server.log` содержит тестовый лог. Поиск подбора паролей:

    grep "ERROR" server.log | awk '{print $8}' | sort | uniq -c | sort -rn

## Темы, которые отработаны

- grep, awk, sed, пайпы
- cron
- права доступа (chmod, chown), пользователи и группы, setgid
- SSH: ключи ed25519, scp, ~/.ssh/config, отключение входа по паролю
